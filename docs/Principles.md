Principle 1

DevBox owns the development environment, not the operating system.
---
Principle 2

DevBox integrates with existing tools instead of replacing them.
---
Principle 3

Everything must be reproducible.
```markdown
    git clone

    ↓

    devbox init

    ↓

    devbox shell
```
---
Principle 4

Platform-specific code belongs in one place.
```markdown
    Runtime

    ↓

    Platform

    ↓

    Windows
    Linux
    macOS
```
