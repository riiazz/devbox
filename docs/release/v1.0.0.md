# v1.0.0 — Reproducible Development Environments

DevBox is a reproducible development environment tool written in Rust. It owns
the development environment — not the operating system — and integrates with
existing tools instead of replacing them.

This is the first stable release. The full pipeline works end to end:
`git clone`, `devbox init`, `devbox shell`, and you are in a reproducible,
isolated environment.

## Highlights

- **Isolated runtime** — `HOME`, `TMP`, `NUGET_PACKAGES`, and `DOTNET_ROOT`
  point into `.devbox/`; no system variables are modified.
- **Tool installs** — `devbox install ripgrep` resolves, downloads, checksums,
  extracts, and registers a tool (Resolve → Download → Checksum → Extract →
  Register).
- **Tool resolution** — `devbox exec rg` finds `.devbox/tools` ahead of the
  system `PATH`, giving you an isolated toolchain.
- **Process supervisor** — `devbox up`, `status`, `logs`, and `stop` manage
  long-running `[services]` with per-service log files.
- **Idempotent `devbox init`** — a second run is a no-op and leaves an existing
  `devbox.toml` untouched.

## Commands

| Command | Description |
|---------|-------------|
| `devbox init` | Create the `.devbox/` workspace and a starter `devbox.toml` |
| `devbox exec <program> [args...]` | Run a program inside the DevBox environment |
| `devbox shell` | Open an interactive shell inside the environment |
| `devbox install <name> [--version <v>]` | Download and register a tool |
| `devbox tools list` / `devbox tools register` | Manage the tool registry |
| `devbox up` | Start and supervise `[services]` |
| `devbox status` | Report service PIDs and status |
| `devbox logs [name] [--lines <n>]` | Print service logs |
| `devbox stop [name...]` | Stop supervised services |

## What's new since 0.9

- **v0.10** — `devbox install` resolves tools through the `[tools]` section of
  `devbox.toml`, overlaid on the built-in manifest.
- **v0.10.1** — `devbox init` is idempotent.

## Supported platforms

- Windows (PowerShell)
- Linux (bash)
- macOS (bash)

## Installing

```text
cargo install --path crates/cli --locked
```

Then, in any project:

```text
devbox init
devbox install ripgrep
devbox shell
```
